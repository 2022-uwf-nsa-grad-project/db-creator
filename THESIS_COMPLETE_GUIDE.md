# Thesis Pipeline - Complete Guide

This guide explains how to generate all results, figures, and tables for your thesis:
**"Predicting Lateral Movement Pivots in Advanced Persistent Threat Campaigns Through Graph Neural Network Analysis"**

---

## 📋 Quick Start

### Step 1: Run the Main Pipeline

Open and execute `thesis_pipeline.ipynb` in order:

```bash
# The notebook will:
# 1. Connect to Neo4j
# 2. Optionally rebuild database (set REBUILD_DATABASE=True if needed)
# 3. Run label-aware analysis (48h/24h windows)
# 4. Run label-agnostic analysis
# 5. Export visualization data
# 6. Generate attack graphs and chain visualizations
# 7. Automatically generate thesis artifacts
```

**Configuration in Cell 2:**
```python
REBUILD_DATABASE = False           # Only True if you need fresh data
RUN_WINDOW_SWEEP = False          # ⚠️ Skip this - already optimized!
RUN_LABEL_AWARE = True            # Generate label-aware results
RUN_LABEL_AGNOSTIC = True         # Generate label-agnostic results
GENERATE_THESIS_ARTIFACTS = True  # Auto-generate all figures/tables
```

### Step 2: Review Outputs

After running the notebook, check these directories:

- **`thesis_results/run_YYYYMMDD_HHMMSS_h48_d24/`** - Raw analysis outputs
- **`thesis_figures/`** - Publication-ready figures and tables

## 🚫 Do I Need to Run the Window Sweep?

**NO!** You can skip the window sweep (`RUN_WINDOW_SWEEP = False`) because:

1. **Already Optimized**: Your thesis uses 48h historical / 24h detection windows
2. **Cell 7 Uses Existing Results**: It loads previous sweep outputs if available
3. **Very Expensive**: The sweep reruns the entire pipeline multiple times (hours of compute)

**When to run it:**
- Only if you want to re-evaluate window combinations from scratch
- Only if your dataset has changed significantly
- For new research questions about window optimization

**The sweep tests these combinations:**
- Historical windows: 3h, 12h, 24h, 48h, 72h
- Detection windows: 3h, 6h, 12h, 24h, 48h
- Total: 25 full pipeline runs (very expensive!)

## 📊 What Artifacts Are Generated?

### Automatically Created by `thesis_pipeline.ipynb`:

1. **CSV Files** (in `thesis_results/run_*/`):
   - `*_pivot_predictions.csv` - Individual window predictions
   - `*_method_comparison.csv` - Performance metrics for all methods
   - `*_chains.csv` - Multi-hop attack chain samples
   - `run_metadata.json` - Run configuration and timestamps
   - `run_summary.json` - Aggregated metrics

2. **Visualizations** (in `thesis_results/run_*/`):
   - `*_ip_graph.png` - Full IP-level attack graph
   - `*_subnet_graph.png` - Aggregated /24 subnet graph
   - `*_chain_network.png` - Multi-hop chain visualization
   - `mode_comparison.png` - Label-aware vs label-agnostic comparison

### Generated by `generate_all_thesis_artifacts.py`:

The artifact generator (auto-run by the notebook) creates:

3. **Tables** (in `thesis_figures/`):
   - `table1_dataset_summary.csv` - Dataset characteristics
   - `table1_dataset_summary.tex` - LaTeX formatted table
   - `table2_performance_comparison.csv` - FastRP performance metrics
   - `table2_performance_comparison.tex` - LaTeX formatted table

4. **Publication Figures** (in `thesis_figures/`):
   - `figure_baseline_comparison.png` - All methods compared (3 metrics)
   - `figure_similarity_distributions.png` - Pivot vs non-pivot distributions
   - `figure_roc_pr_curves.png` - ROC and PR curves for FastRP
   - `figure_subnet_pivot_heatmap.png` - Top 15 subnets by pivot activity
   - `figure_temporal_analysis.png` - 4-panel temporal pattern analysis

5. **Statistical Summary**:
   - `statistical_summary.txt` - Key numbers for thesis text

## 🔄 Re-Running the Artifact Generator

If you want to regenerate just the figures/tables without rerunning the full pipeline:

```bash
python generate_all_thesis_artifacts.py
```

This script:
- Finds your latest `thesis_results/run_*` directory
- Loads the CSVs from that run
- Generates all figures and tables
- Takes ~30 seconds (vs hours for full pipeline)

## 📝 Using Outputs in Your Thesis

### For Markdown/LaTeX Documents:

1. **Copy figures**:
   ```bash
   cp thesis_figures/*.png your_thesis_folder/figures/
   ```

2. **Insert in LaTeX**:
   ```latex
   \begin{figure}[h]
   \centering
   \includegraphics[width=0.8\textwidth]{figures/figure_roc_pr_curves.png}
   \caption{ROC and Precision-Recall curves for FastRP embeddings.}
   \label{fig:roc-pr-curves}
   \end{figure}
   ```

3. **Use generated tables**:
   - Copy `table1_dataset_summary.tex` directly into your LaTeX document
   - Or convert CSV to Markdown tables for Markdown-based thesis

4. **Reference numbers**:
   - Open `statistical_summary.txt`
   - Copy key metrics into your Results chapter

1. Upload all `.png` files from `thesis_figures/` to your Overleaf project
2. Upload `.tex` table files directly
3. Reference them in your main document

## 🐛 Troubleshooting

### "No run directories found"
**Problem**: Artifact generator can't find results
**Solution**: Run `thesis_pipeline.ipynb` first (cells 1-13)

### "Missing *_method_comparison.csv"
**Problem**: Analysis didn't complete
**Solution**: Check notebook output for errors in cells 9-11

### Figures look wrong
**Problem**: Data may be corrupted or incomplete
**Solution**: 
1. Set `REBUILD_DATABASE = True`
2. Rerun full pipeline
3. Regenerate artifacts

### Out of memory errors
**Problem**: Dataset too large for available RAM
**Solution**:
- Reduce `CHAIN_SAMPLE_LIMIT` in Cell 13
- Set `max_edges_per_node=25` (instead of 50)
- Close other applications
